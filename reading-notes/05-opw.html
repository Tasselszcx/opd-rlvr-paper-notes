OPW：先让老师纠正学生，再让学生自己做 RL

From Imitation to Reward Discovery: On-Policy Warmup for Agentic RL

Qiao, He, Liu et al.2026-09-30 · 2609.39436v1论文 ↗本地 PDF ↗
先看例子怎么做公式解释容易混淆处结果论文区别
学生先自己做任务，老师在学生走到的位置给下一步建议。先这样训练 40 步，再撤掉老师，做 60 步 RL。论文要看：老师离开以后，学生是不是更容易学好。

说明性例子

从“拿错杯子”开始看

假设任务是把洗干净的杯子放到桌上。学生模型却拿起了盘子，然后连续两次执行无效命令。普通的成功示范可能只有“找到杯子、清洗、放好”这条路线，学生没有从中学过拿错东西之后怎么办。

OPW 会保留学生走错的这段记录，再让老师看着这段记录，判断下一步更应该生成什么。即使整次任务最终失败，这些位置仍然能用来训练学生。下面就沿着这次任务解释它怎么做。

01具体怎么做

谁 / 什么数据负责什么
学生模型负责生成动作、与环境交互，之后接受参数更新。
老师模型只在前 40 步提供建议；这段时间老师参数不更新。
环境执行学生动作、返回观测，并在 RL 阶段给任务奖励。

1. 先让学生独立做完一批任务

给学生一条任务指令，让它按自己的概率生成推理和动作。每次动作都交给环境执行，环境返回的信息再放回上下文。例如“盘子已经拿起”就是后续行动必须面对的事实。收集时由学生行动，老师不会替学生把轨迹改成一条完美路线。

一次轨迹记录了任务、学生输出和环境回复。这里经常出现的 prefix，指的就是某个输出位置之前已有的全部记录。它决定了模型此刻能看到什么。学生犯错后形成的 prefix，也会进入训练数据。

2. 让老师逐个位置看学生的记录

把这些记录交给固定老师。在每个学生输出位置，老师回答一个具体问题：看完前面这些内容，下一 token 最应该是什么？例如学生原来想继续重复一个无效命令，老师可能更倾向于生成另一个动作。

主实验取老师概率最高的 token 当目标。这里不要求老师先把任务重新做成功，也不要求把整条失败轨迹扔掉。老师只要能在学生访问过的位置给出有用建议，就能提供训练信号。环境回复只作为输入，不当作学生需要学习生成的答案。

3. 用老师目标训练学生，再重新采样

假设学生在某位置给老师建议的 token 概率只有 0.1。交叉熵训练会提高这个概率，让学生下次到达相似位置时更容易选中它。学生参数因此改变；老师保持不变。本文不是给整条失败回答一个正标签，而是在其中各个输出位置学习老师目标。

更新后再让新学生做任务，收集它现在会走到的位置，再评分、再训练。这个过程比一直复用最初一批错误记录更贴近当前学生。主实验重复四十个 warmup 更新步；一步处理一批任务，不是只做一个动作。

这一步训练什么

$$L_{warm}=-\sum_{t\in M}\log\pi_S(a_t^T\mid h_t)$$

hₜ 是学生在该位置前的记录，aᵀₜ 是老师建议的 token。损失越小，学生给老师建议的概率越大。M 只包含模型输出的位置。

4. 撤掉老师，继续用任务奖励训练

四十步以后保存学生，去掉蒸馏损失和老师查询，开始六十步 GRPO。此时学生对同一个任务采样多条轨迹，根据任务完成情况比较好坏，再增加较好轨迹的概率。warmup 与后续 RL 使用分开的训练任务池。

ALFWorld 的结果奖励是任务是否成功；ScienceWorld 还有部分进度得分。主比较还训练了一百步纯 GRPO、一百步纯 OPD，以及其他四十步 warmup 加六十步 GRPO 的组合，所以能看清楚前四十步采用哪种训练更有帮助。

5. 看老师退出之后，奖励是不是更容易学到

如果学生对同一任务试了八次，全都失败，八个奖励都是零，GRPO 无法从这一组里比较出谁更好。假如 warmup 让其中一次成功，就有了成功和失败之间的差别。论文把这种更容易遇到有效奖励的现象作为解释之一。

但论文也观察到，初始成功覆盖不是越高，后续 RL 就必然越好。因此还要看学生是否减少重复错误、能否反复稳定完成任务，以及整个 RL 过程中成绩如何变化，不能只比较 warmup 结束那一个分数。

02容易弄混的地方

为什么不直接学老师的成功轨迹？

因为两种训练看到的位置不同。成功示范会教“怎么顺利走过去”；OPW 还会教“学生已经走错以后怎么办”。这不是保证老师在任何错误状态下都能救回来，而是把监督放到学生实际会碰到的位置。

理论里的 KL 和实验损失是一回事吗？

不是。理论用累积 reverse KL 连接整条轨迹的分布和初始成功率，实验用老师 top-1 token 的交叉熵。你可以用理论理解作者的动机，但复现时应按实际损失实现，不能把理论下界直接当成交叉熵训练的保证。

看表里 ALFWorld Unseen 这一列：OPW 后接 GRPO 达到 96.7，直接 GRPO 是 86.6。这说明在这套模型、任务和步数配置下，先让老师纠偏比从头只用奖励更有效。ScienceWorld 的数值是任务得分，不能和 ALFWorld 的成功率混用。

一个更具体的消融是去掉重复无效动作处的老师监督。这样做以后，后续早期 GRPO 的提升小于随机删掉相近数量 token 的对照，说明监督放在哪些错误位置确实有影响。总成本还随模型大小变化：算 warmup 值不值，必须把老师评分也算进去。

04和其他论文的区别

和你的流程最接近的是这篇：固定老师先教，老师退出，学生独立做 RL。若要再学习“何时教、教哪里”，先在相同老师调用量和 RL 步数下，证明它比普通 OPW 更好。

实验对照建议

固定 teacher 的 OPD warmup 已能改善奖励发现与后续 RL。需要进一步证明，可学习指导在同样老师调用、学生训练和 teacher-free RL 预算下，比固定 teacher 加合理 warmup 时长更好。

OPW 做的事就是：先在学生自己的错误经历上学老师，再让学生只靠任务奖励继续练。
