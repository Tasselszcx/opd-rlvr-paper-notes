OPD 与 RLVR

11 篇论文的具体做法、训练步骤与实验结果。

OPD：学生自己写，老师给反馈

学生生成回答，老师看着已生成的内容，给下一 token 的概率或目标。学生据此更新。

RLVR：用可验证结果学习

学生先回答或行动，再根据答案检查、代码测试或环境结果获得奖励，用这些奖励更新模型。

01老师来源

RISE

把刚才的 RL 更新放大，做成老师

学生先做一次 RL 更新。把新旧模型的变化再向前放大一点，得到临时老师；让学生学这个老师的预测，然后进入下一轮。

02教学与成本

SOAR

老师先出题，学生练完真有进步，老师才得到奖励

老师生成一小组题和答案，学生在这些题上真实训练十步。再去原来的难题上测成绩，进步多少就给老师多少奖励，让老师逐渐学会出有帮助的题。

03老师来源

NPO / NPD / AutoNPO

用后面的 checkpoint 教前面的模型

先把模型往后训练，保存一个更强的版本；再恢复较早的模型，让后面的版本教它。NPO 传成功回答，NPD 传 token 概率，AutoNPO 决定什么时候回滚。

04训练顺序

Sequential Beats Joint

先只做蒸馏，再只做 RL

把训练拆成两段：前一段只让学生学固定老师，后一段撤掉老师，只按任务奖励训练。论文把它和每一步同时混合 OPD、RL 的做法作比较。

05训练顺序

OPW

先让老师纠正学生，再让学生自己做 RL

学生先自己做任务，老师在学生走到的位置给下一步建议。先这样训练 40 步，再撤掉老师，做 60 步 RL。论文要看：老师离开以后，学生是不是更容易学好。

06监督分配

MetaOPD

先试一次更新，再学怎样给 token 分权重

一个小网络给学生回答中的 token 分配训练权重。先按这些权重试着更新学生，再用参考解答检查这次更新有没有帮助；检查结果用来改小网络，随后才真正更新学生。

阅读详解 →
07训练顺序

PEAR

根据后续示范是否好学，调整每一步的训练权重

数据还是原来的离线示范，PEAR 只改变每个位置学多大力度。它比较学生与数据来源模型的概率，降低那些后续整段示范对学生很难继续的位置的权重。

08监督分配

Dr. OPD

用任务奖励决定，哪些老师纠正要多学

老师会在很多 token 上纠正学生，但这些纠正未必同样有用。Dr. OPD 用结果奖励判断：加强某个位置的纠正，会不会帮助学生把题做对？有帮助就加权，没帮助就减权。

09教学与成本

OP-Short

学生先走，老师接手几步，把这几步拿来训练

让学生自己执行任务，随机选一个位置交给老师。老师只继续少量交互步，这些短续写都保留，再用它们训练学生。论文比较这样花老师预算是否更划算。

10训练顺序

RL Starts before RL

蒸馏以后，把 RL 接完再比较

作者训练几种不同的学生起点，再给它们相同的 RL。结果发现：刚蒸馏完分数更高的模型，接着 RL 后不一定更好；选择蒸馏方法时，评价终点要往后移。

11老师来源

ATESD

决定老师能看多少参考解答

学生只看题目，老师额外看参考解答，再给学生指导。ATESD 加一个小控制器，决定老师每次能看多少推理过程；最终答案始终给老师看。

方法对照

论文具体做什么老师或数据关键区别
RISE放大最近一次 RL 的变化来造老师按新旧模型计算每轮重新造老师再蒸馏
SOAR学生练完老师题集，用真题进步奖励老师可训练的出题模型真实训练十步后评价
NPO / NPD / AutoNPO用较晚 checkpoint 教较早模型真实训练过的未来自己NPO 搬回答，NPD 搬概率
Sequential Beats Joint先纯 OPD，随后只做 RL固定外部老师在第二段撤掉老师信号
OPW先用老师训练 40 步，再独立 RL固定大老师老师只在前一段参与
MetaOPD试一次更新，再训练权重网络固定老师 + 参考解答试更新后恢复原学生再正式更新
PEAR给离线示范的每个位置换权重固定示范与来源概率看后面的示范是否容易被学生继续
Dr. OPD用奖励判断哪些纠正应该多学固定老师 + 结果奖励每轮计算各 token 的权重
OP-Short随机交接，让老师只续写几轮固定老师接管环境把短续写留下来做 SFT
RL Starts before RL比较不同起点接完 RL 的结果固定外部老师蒸馏后的高分不保证最后高分
ATESD决定老师能看多少参考推理同模型 + 部分参考解答学生仍只看题目

不同论文的模型、任务和训练量不同，这里比较做法，不直接比较分数。
