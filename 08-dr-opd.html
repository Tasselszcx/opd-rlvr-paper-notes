Dr. OPD：用任务奖励决定，哪些老师纠正要多学

Dr. OPD: Learning What to Follow for Optimal On-Policy Distillation of Large Language Models

先看例子怎么做公式解释容易混淆处结果论文区别
老师会在很多 token 上纠正学生，但这些纠正未必同样有用。Dr. OPD 用结果奖励判断：加强某个位置的纠正，会不会帮助学生把题做对？有帮助就加权，没帮助就减权。

说明性例子

关键计算和一句措辞，不必学得一样用力

假设学生写错了一步乘法，又写了一句和老师不同的过渡语。普通 OPD 会在两个位置都要求学生接近老师。Dr. OPD 想区分：哪个纠正更有利于最终答案正确，哪个只是让文字更像老师。

算法不会人工标注“乘法重要、过渡语不重要”。它根据当前模型的梯度和整题奖励来算。下面用这两个位置作示意，解释权重究竟从哪里来。

01具体怎么做

谁 / 什么数据负责什么
学生先生成一组完整回答，再接受加权 OPD 更新。
老师对这些学生回答逐位置给概率；老师参数不更新。
结果奖励数学检查答案，代码执行测试；用它估计学生该往哪边更新。

1. 先收集学生回答和两类反馈

对同一题让学生生成多条回答。老师读取这些回答的前缀，给每个已采样 token 一个概率；verifier 检查完整回答，给对错或任务得分。因此一条回答同时有逐 token 的老师评分和整条回答的结果奖励。

这两个反馈回答不同问题：老师评分告诉你这个 token 像不像老师会选的；结果奖励告诉你整条回答有没有做成任务。Dr. OPD 接下来要判断，朝老师靠近的方向是否也有利于任务奖励。

2. 算出每个位置的老师纠正方向

取老师概率的对数减去学生概率的对数，记作 dₜ。若老师给当前 token 的概率更高，dₜ 为正，就倾向于提高它；若老师给得更低，就倾向于降低它。再乘学生 log-probability 对参数的梯度，得到这个位置的纠正方向 gₜ。

这里说的方向，是“参数怎样改变，才会让学生更愿意或更不愿意输出这个 token”。所以不能只按词的表面含义决定重要性。同一个词出现在不同题目、不同前缀，或者不同阶段的学生里，计算出的纠正方向都可能不同。

3. 用结果奖励算另一个方向，再比较两者

根据同一题各条回答的奖励差异，构造一个能提高学生任务表现的更新方向。做对的回答和做错的回答贡献不同，和 GRPO 用组内好坏来学习的思路相同。之后把这个奖励方向与每个 gₜ 做内积，得到 token credit。

正 credit 表示这两个方向在当前计算里相互支持，可以多听这个位置的老师；负 credit 表示更强地模仿它可能妨碍奖励改善，应当少听一点。论文理论在一次普通 OPD 更新之后评价奖励梯度，实装为节约计算，用当前学生已有回答来近似。

从两个方向得到权重

$$\begin{aligned}c_t&=\langle g_t,\widehat r\rangle\\w_t&=\operatorname{clip}(1+\lambda\widetilde c_t,w_{min},w_{max})\end{aligned}$$

r̂ 是估计的奖励改善方向，cₜ 是两方向的内积。实际先把 credit 按 RMS 尺度缩放成 c̃ₜ，再乘 λ、加到一上，最后限制上下界。

4. 按权重更新学生，老师本身不变

原来各位置都按相同力度做 OPD，现在把每个位置的老师信号乘 wₜ。例如缩放后的 credit 是 +1、λ 是 0.4，那么未触发截断时权重为 1.4；credit 为 −1 时是 0.6。两个位置都还能学，但力度不同。

因此负 credit 并不意味着把老师建议完全反过来训练。主配置通过正的权重下界保留一定监督。更新完学生后，下一轮重新生成回答、重新计算 credit，权重也随之变化；没有一个额外网络永久记住每种 token 的权重。

5. 怎样算这么多 token，而不保存巨大梯度表

如果每个 token 都保存一份完整参数梯度，大模型会占很多内存。实际上这里只需要“这个梯度沿同一个奖励方向的投影”。JVP 可以输入那个参数方向，一起算出所有 token 概率沿这个方向的变化率，再与 dₜ 组合成 credit。

公开代码中，jvp_influence.py 计算方向导数，credit_gate.py 做缩放和权重截断。其余训练代码把权重用于 OPD。工程实现还处理有效 token、参与加权的位置以及优化器状态；下方保留了具体代码链接，读完流程后可以再看。

02容易弄混的地方

它和 OPD loss 加 RL loss 有什么区别？

直接相加会让两份损失各自贡献梯度。Dr. OPD 先用奖励判断哪些老师纠正值得加强，再做加权 OPD。结果奖励在这里控制的是听老师的力度，不能把它当成换个系数的普通 loss 相加。

一组回答全错时，还能算出好权重吗？

如果结果奖励都一样，组内比较提供的方向很弱，credit 就难以可靠区分有用纠正。论文里更弱 Base 学生的数学收益也较小。这个方法需要一定可用奖励，不能单靠加权解决所有零成功冷启动。

它在这组数学平均上超过 4B 老师，但代码平均仍低于老师，所以不要把结果读成小模型全面超过大模型。理论也只是特定条件下的局部更新结论；实际 credit 使用近似，不能保证每一次加权更新都提高分数。

04和其他论文的区别

MetaOPD 也改 token 权重，但它训练一个小网络，并用参考答案上的预测损失教这个网络。Dr. OPD 直接用本轮任务奖励算权重，没有这个额外网络。

实验对照建议

它已把 outcome reward 转成监督的局部信用。若延伸到多步独立 RL，需要说明信用如何穿过后续策略变化，以及长反馈是否比当前局部估计更值得付费。

先问老师想纠正什么，再问这种纠正是否有助于奖励，最后决定学多大力度。
