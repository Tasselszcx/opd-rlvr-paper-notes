RL Starts before RL：蒸馏以后，把 RL 接完再比较

RL Starts before RL: On Policy Distillation for Better Reinforcement Learning

Dong, Zhu, Xu et al.2026-09-26 · 2609.28145v2论文 ↗本地 PDF ↗
先看例子怎么做公式解释容易混淆处结果论文区别
作者训练几种不同的学生起点，再给它们相同的 RL。结果发现：刚蒸馏完分数更高的模型，接着 RL 后不一定更好；选择蒸馏方法时，评价终点要往后移。

说明性例子

现在分数高，和接下来学得好，可能不是一个学生

假设两种蒸馏得到学生甲和学生乙。甲现在做题正确率略高，所以只看蒸馏结果，你会选甲。但把同样的数据、奖励和训练步数交给它们继续 RL 后，乙反而达到更高分。

这篇就是通过一组这样的对照，检查哪种训练准备更适合后续 RL。它主要提供实验发现和解释，没有另外提出一个复杂的新教师控制器。

01具体怎么做

谁 / 什么数据负责什么
三种起点原模型直接 RL、先 SFT 再 RL、先 OPD 再 RL。
师生规模文本与视觉语言各有一组 8B 学生、32B 老师。
比较方式每组实验的后续 RL 数据、奖励和优化配置保持一致。

1. 先准备 Base、SFT 和 OPD 三种学生

Base 不做前面的老师训练，直接进入 RL。SFT 让学生学习老师已经生成并验证正确的回答。标准 OPD 则让学生自己生成回答，老师在这些学生前缀上提供完整概率分布，学生用 reverse KL 来学习。

两种老师训练都可能提高当前分数，但它们让学生接触的数据位置和训练目标不同。SFT 主要沿老师轨迹学下一 token，OPD 会沿学生自己写出的文字学习老师概率。这些变化是否帮助后续 RL，要继续训练才知道。

2. 给三种起点接相同的 RL

在每组设定内，使用相同的 GRPO-style 训练数据、验证器、优化器和采样配置。从各自的准备 checkpoint 出发，记录 RL 前后成绩。准备阶段与 RL 阶段使用分开的题目数据，测试题也不拿来更新模型。

文本实验特别直观：Base 和 OPD 在 RL 前平均分很接近，分别为 36.48 和 37.02；RL 后变成 51.90 和 59.18。初始只差 0.54 点，最后差 7.28 点，说明前一段训练的作用没有全部体现在即时分数上。

3. 检查是否只是 OPD 让正确答案更容易被采到

作者另选共同的诊断题，对每个起点每题采样六十四次，比较 Pass@k、答对次数，以及一组回答中全错或有对有错的比例。如果 OPD 的优势只是提前产生更多成功回答，这些统计应该能反映出很大区别。

但文本 Base 与 OPD 的 Pass@64 分别约为 80.4 和 80.0，十分接近，后续 RL 却差得很大。这个结果说明测到的初始覆盖不够解释全部收益。它不意味着覆盖无关，因为相同总比例也可能来自不同题目和不同推理路径。

4. 再看 token 概率，而不只看最可能的词

假设老师对 A、B、C 给概率 0.6、0.3、0.1。学生甲给 0.98、0.01、0.01，学生乙给 0.55、0.35、0.10。两者最可能输出的都是 A，但甲几乎不考虑 B，乙还保留 B 这条选择。这是说明分布差异的例子，不是论文实验数值。

作者因此检查 top-20 概率分布的 JS 差异、top-1 是否一致，以及一些推理词位置的熵。OPD 在这些诊断里更接近老师的分布，同时保留较多其他选择；SFT 即使最大概率词更常一致，也不一定具有相同性质。

5. 最后交换 KL 方向，看看选择会不会反过来

在视觉语言实验里，再比较学生轨迹上的 forward KL 与 reverse KL。FKL 更强调学生不要漏掉老师支持的续写；RKL 更惩罚学生把概率给老师不支持的续写。训练后先测一次，再给两者接相同 RL，再测一次。

RKL 蒸馏后的分数略高，但后续 RL 结束时 FKL 更高。作者又把采样轨迹换成老师轨迹，此时仍是 RKL 更好。所以“用哪种 KL”与“在哪些前缀上学习”要一起比较，不能只根据其中一项推出通用答案。

两个 KL 为什么会有不同效果

$$\begin{aligned}D_{FKL}&=\sum_v p_T(v)\log\frac{p_T(v)}{p_S(v)}\\D_{RKL}&=\sum_v p_S(v)\log\frac{p_S(v)}{p_T(v)}\end{aligned}$$

v 是候选 token。第一行按老师概率给各项加权，第二行按学生概率加权；所以相同的概率差，在两种损失里受到的关注不同。

02容易弄混的地方

作者认为 OPD 为什么有帮助？

一种解释是，老师调整了学生对不同续写的概率，同时保留了一些可以继续尝试的选择。后续奖励再帮助学生选得更准。这是由行为诊断支持的解释；论文没有把概率对齐和保留不确定性的独立因果贡献完全分开。

保留更多不确定性总是好事吗？

不是。随机模型也可能很不确定，却没有有用解法。这里讨论的是学生接近较好老师的预测，同时保留可以被奖励进一步选择的续写，不能把它简化成只提高熵就能让 RL 更好。

老师轨迹那组，就是普通 SFT 吗？

也不是。那组实验仍然给学生完整的老师概率分布，只把回答的生成者从学生换成老师。这样主要比较的是在哪些前缀上训练，而不是同时把软概率目标换成硬标签。把这两种变化分开，才能知道结果差在何处。

04和其他论文的区别

OPW 研究在 agent 任务上如何做 warmup；这篇提醒你，评价任何 warmup 时，都要看老师离开后学生继续训练的结果。

实验对照建议

即时分数与后续价值会排序反转，但这不自动证明必须做复杂元优化。应以同一批指导候选检验短期代理、Pass@k 与真实独立 RL 收益各自能预测多少。

别只问蒸馏以后学生考了多少分，还要问它继续 RL 以后能学到多少。
