PEAR：根据后续示范是否好学，调整每一步的训练权重

Good SFT Optimizes for SFT, Better SFT Prepares for Reinforcement Learning

Zhang, Xu, Wang et al.ICML 2026 ↗2026-05-28 · 2602.01058v2论文 ↗本地 PDF ↗
先看例子怎么做公式解释容易混淆处结果论文区别
数据还是原来的离线示范，PEAR 只改变每个位置学多大力度。它比较学生与数据来源模型的概率，降低那些后续整段示范对学生很难继续的位置的权重。

说明性例子

同样写“因此”，后面接的内容可能完全不同

假设两条示范都写到“因此”。第一条后面接学生熟悉的代数推导，第二条后面接学生几乎不会使用的一串构造。学生对“因此”这个词本身的概率相同，但接下来的两条路很不一样。

PEAR 会查看这个位置之后的整段示范，比较它在学生和来源模型下有多容易出现，再决定当前位置学多大力度。它希望这样训练出来的学生，后面做 RL 时更容易继续学习。

01具体怎么做

谁 / 什么数据负责什么
离线示范固定的题目与回答，主实验由 Qwen3-8B 生成并验证。
两份概率数据来源模型的 token 概率，以及当前学生对同一离线文本的概率。
更新与评价前一段做加权 SFT 或离线 KD，后一段接同样 RL 比较结果。

1. 先让两个模型读取同一条离线回答

取已有的题目和示范回答，不让学生另写一条。对回答中每个位置，数据来源模型和学生都看到相同前文，计算这个示范 token 的概率。来源模型概率可以提前保存；学生概率随自己的参数变化重新计算。

这里的来源模型是生成数据的策略，不是一个假设的最优模型。若数据来自拿不到概率的闭源服务，论文还研究了用代理模型估计来源概率，但那样得到的概率比只是近似。实际使用时要先弄清楚示范是从哪里来的。

2. 把学生概率除以来源概率

如果来源模型给一个示范 token 概率 0.8，而学生只给 0.4，那么比率是 0.5。意思是：和来源模型相比，当前学生更不容易写出这一步。若学生概率更高，比率就大于一。

这个比率本身并没有判断示范对不对。正确但新颖的知识也可能在学生下概率很低。PEAR 用它衡量示范与当前学生的关系，再通过后续实验检查这种重加权是否有利，不能把概率低直接解释成内容错误。

3. 为当前位置计算后缀权重

逐 token 版本不只使用当前位置的比率，而把它后面各位置的比率相乘。若后面三个比率都是 0.5，先忽略折扣，乘积就是 0.125，于是当前位置的损失会被减弱。作者想减少对那些学生很难继续完成的示范路径的模仿。

公式还按剩余长度乘一个折扣。越长的序列连乘越容易不稳定，所以实际在 log 空间相加，并对单步比率和最终权重截断。纸面连乘是核心想法，带截断的计算才是实际训练配方。

当前位置看的是后面哪些词

$$\begin{aligned}\Delta_j&=\frac{\pi_S(y_j\mid x,y_{<j})}{\pi_B(y_j\mid x,y_{<j})}\\G_t&=\gamma^{T-t}\prod_{j=t+1}^{T}\Delta_j\end{aligned}$$

B 是数据来源模型，S 是学生，T 是回答长度。第 t 个位置的权重用 j>t 的后续示范计算，γ 控制折扣。

4. 把这个数乘到原损失上，再更新学生

如果原来某位置的 SFT 交叉熵是 ℓₜ，现在训练的是 Gₜ×ℓₜ。原来的监督目标不变，只改变每个位置的力度。权重会停止梯度，因此学生不会沿着“怎样改变 Gₜ”这条额外路径优化。

这套做法没有额外的教师网络，也不会为了算一个权重先跑一段学生 RL。它还可以作用于离线 KD 的 token 损失。论文另外给出负样本扩展，用序列权重降低验证失败回答的概率；比较时需要分清有没有使用这部分数据。

5. 选权重版本，然后把后续 RL 接完

论文有三个版本。序列版把整条回答的比率相乘，所有位置共用一个数；token 版每个位置使用自己的后缀；block 版把相邻 token 分块，同一块使用块末之后的后缀。它们在细粒度和稳定性之间作不同选择。

离线训练完后，把这些学生和普通 SFT 学生都送进相同 RL。此时比较的是完整训练的最终表现。后续 RL 只用于验证准备效果，不会作为外层奖励直接训练 PEAR 的权重规则。

02容易弄混的地方

这和只看当前 token 的权重有什么区别？

回到“因此”的例子：单步权重看到两个当前词的比率一样，就给同样力度；后缀权重还看后面能否继续。论文专门比较了同样稳定化的单步比率，结果说明随便加一个概率权重并不足够。

它为什么适合作为便宜基线？

它保留现成的 SFT 数据与训练流程，额外主要是来源概率和权重计算，不用展开真实或虚拟的多步学生训练。不过概率预计算、代理模型评分和示范生成仍要花钱，不能把这些前置费用省略。

序列级这个更简单的版本也表现不错。因此，你要研究可学习 gate 时，不应只和均匀 SFT 比，还要比较序列、token 和分块这些便宜版本。所有方法接相同后续 RL，才容易看清新增复杂度带来了多少收益。

04和其他论文的区别

MetaOPD 会根据一次临时学生更新的结果学习权重网络；PEAR 直接按预设的概率比规则算权重。两者都重分训练力度，但算权重的过程和费用差很多。

实验对照建议

保留序列级、后缀 token 级和分块 PEAR 三个便宜版本，并明确来源概率成本。你的复杂教学策略要展示超过这种预设重加权规则的增益。

PEAR 不换示范答案，只根据后续示范与学生的关系，改变每一步学多大力度。
