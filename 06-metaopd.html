MetaOPD：先试一次更新，再学怎样给 token 分权重

MetaOPD: Meta-Learned Token Weighting for On-Policy Distillation

Wang, Dong, Wang et al.2026-10-08 · 2610.11989v1论文 ↗本地 PDF ↗
先看例子怎么做公式解释容易混淆处结果论文区别
一个小网络给学生回答中的 token 分配训练权重。先按这些权重试着更新学生，再用参考解答检查这次更新有没有帮助；检查结果用来改小网络，随后才真正更新学生。

说明性例子

先试权重，再决定这一步怎么学

假设一条回答有两个值得纠正的位置，小网络起初都给权重一。按这组权重试着更新学生后，用另外一批参考解答计算预测损失。这个损失会告诉网络：把更新量更多放到哪个位置，可能让这一步学得更好。

这里“试着更新”会产生一份临时学生参数，不会直接覆盖真实学生。小网络改好权重后，才从原来的学生参数和优化器状态出发，做真正的一次更新。

01具体怎么做

谁 / 什么数据负责什么
学生生成回答，并接受最终的加权 OPD 更新。
固定老师在学生回答的位置给 token 概率。
权重网络根据师生预测特征给 token 权重；由参考解答损失训练。

1. 先收集普通 OPD 所需的回答和老师评分

学生对训练题生成回答，老师对相同前缀给出概率。保留采样时的学生概率、老师概率以及哪些位置是真实输出 token。它们用于构造普通 OPD 的逐 token 更新信号，也供后面的小网络判断这些位置的状态。

这时还没有更新学生。参考解答也不直接作为这条学生回答的正确续写插进去。这里仍然是学生自己生成，老师在学生自己的文字上给监督。

2. 把每个位置变成一组数字，交给权重网络

输入特征一共七十四维，包括师生给当前 token 的概率及差值、两边的熵、最可能 token 是否相同、位置，以及各自 top-32 的概率列表。它们描述这个位置的预测情况，网络并不直接读取一段完整参考答案来决定权重。

这些输入数字会 detach，也就是从学生的反向传播计算里断开。网络输出分数后，再把它变成正权重，并让每条回答的平均权重等于一。这样主要改变的是位置之间的训练分配，不是把整条回答的损失都随意放大。

权重乘在原 OPD 损失上

$$L_{in}=\frac1N\sum_t w_\eta(f_t)\ell_t^{OPD}(\theta)$$

fₜ 是该位置的特征，wη 是小网络给的权重，ℓOPD 是原来的 token 损失。全给一时，就是均匀加权的 OPD。

3. 模拟一次真实会发生的 AdamW 更新

按当前权重计算学生梯度，再模拟一次 AdamW 更新，得到临时参数 θ′。模拟会使用当前真实优化器的动量、二阶矩、学习率和梯度裁剪，而不是只写成一个粗略的减梯度操作。因为这些状态会影响同一份梯度最终把参数推到哪里。

真实学生参数、真实优化器状态和步数都暂时不变。这份临时学生只用来评价刚才的权重。网络不需要穷举所有权重组合，而是保留“权重怎样影响这次更新”的可微关系，随后用梯度计算怎样改它。

4. 用参考解答检查临时学生，并更新小网络

拿一批题目和参考解答，让临时学生沿参考解答的前缀预测下一 token，计算负对数似然，也就是 NLL。若这次更新让参考 token 更容易被预测到，NLL 会更低。梯度穿过临时更新，告诉权重网络怎样分配更有利。

论文把它叫 validation loss，但这批参考解答来自训练集的另一个打乱数据流，不是测试集，两条训练流也允许题目重叠。另有一个正则项，让权重别在证据不足时离均匀分配太远。完成这一步后，改变的是小网络参数。

5. 丢掉临时学生，用新权重真正更新

用改好的小网络对同一批特征重新计算权重。然后丢弃 θ′，从原始学生参数和原始优化器状态出发，做真实的加权 OPD 更新。真实更新时把权重当常数，不再顺便训练小网络。

不能直接在临时 θ′ 上继续走，否则学生实际经历了两次更新，和刚才评价的操作不同。下一批再重复同样流程。计算上用 VJP、JVP 避免保存每个 token 的完整参数梯度，但临时更新和参考解答计算仍然需要大模型算力。

02容易弄混的地方

它是不是直接多做了一遍 SFT？

参考解答的损失用来训练权重网络，真实学生目标仍是加权 OPD。这和直接把 SFT loss 加到学生目标上不同。但参考标注确实参与了训练，因此也不能宣称方法完全不需要参考解答。

小网络为什么还会带来接近两倍成本？

便宜的是权重网络本身。昂贵的是为评价它而做的临时学生更新、参考解答前向以及穿过更新求导。论文在 1.7B 设置下记录到 45.0 对 88.5 GPU-hours，比较时应使用这类整套训练成本。

表中的 Avg@8 是八次回答的平均准确率，Pass@8 是八次里至少答对一次的比例。后者增长更明显，表示学生能在多次尝试中找到正确答案的题更多，不能把两个指标当作同一种准确率。

作者做了只输入位置、熵或概率差的消融，也比较了直接加 SFT loss 的做法。完整特征平均效果更好，但并非每个 benchmark 都提高。这里评价的是一次虚拟更新后的参考预测能力，尚不能直接说明它已经找到长期 RL 回报最大的 token 权重。

04和其他论文的区别

SOAR 会让学生真实训练多步，再用任务准确率奖励老师；MetaOPD 模拟一步，用参考解答损失更新权重网络。二者花的计算、用的反馈和教的东西都不同。

实验对照建议

一步虚拟更新后的参考 loss 已能训练权重网络。更长 RL 反馈应证明一步代理在哪些任务上排序错误，并与它约翻倍的实测训练成本一起比较。

先用一次临时更新教会小网络怎样分权重，再用改好的权重真正更新学生。
